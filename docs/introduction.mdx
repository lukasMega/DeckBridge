**DeckBridge** lets you use a USB Stream Deck with the Elgato Stream Deck app over your
local network. The Elgato app sees it as a network device, so keys and button images work
over WiFi. You do not need an
[Elgato Network Dock](https://www.elgato.com/us/en/p/network-dock-stream-deck).

It is free, community-built, for personal and hobby use. One **standalone binary**
(&lt;5MB, no Node.js).

> New here? Go to **[Getting Started](/getting-started)**.

:::caution[Experimental project]
DeckBridge is experimental. The author will not add new devices, but welcomes pull
requests that prove the hardware works. Only grids of 6 buttons (3×2, like the Stream Deck
Mini) up to 15 buttons (5×3, like the MK.2) are supported.
:::

## How it works

DeckBridge talks USB HID to the deck. On the network it acts like an Elgato Network Dock
(TCP/CORA, advertised over mDNS). Key presses go up. Button images go down, resized and
rotated per device.

Hardware-tested on macOS: Stream Deck MK.2, Stream Deck Mini, 293V3, 293S, K1 Pro, and
Fifine AmpliGame D6 (rev. 2). All other models, and the Linux and Windows builds, are
implemented but not hardware-verified.

<details>
<summary>Shared hardware and the Ulanzi D200</summary>

- Ajazz AKP153 rev. 2 and Fifine D6 are the same hardware as the 293V3 with another USB
  VID/PID. They reuse the 293V3 model. The D6 has two revisions that differ only in USB
  packet size: 512 bytes (PID `0x0007`) and 1024 bytes (PID `0x0060`).
- The 7 v1 rebadges of the 293S board (Ajazz AKP153/E/R rev. 1, Mars Gaming MSD-ONE, Mad
  Dog GK150K, Risemode Vision 01, TMICE Stream Controller) reuse the 293S model.
- The **Ulanzi Stream Controller D200** shares no board with the others. Its firmware
  repaints the grid from a ZIP (`manifest.json` + `Images/*.jpg`) sent by the host. It has
  its own driver (`ts/src/devices/ulanzi/`), built from public docs and hardware-tested on
  macOS. The 13 LCD keys work. The wide bottom-right slot keeps the firmware's clock.

</details>

:::caution[Platform status]
DeckBridge is **hardware-tested on macOS only**. Releases ship macOS (`arm64`, `x86_64`),
Linux (`x86_64`, `arm64`) and Windows (`x86_64`, NSIS installer) builds. Linux and Windows
get much less real-world use. See [Headless Linux](./headless-linux.md) (glibc 2.38+).
:::
