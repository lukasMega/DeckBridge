Deckbridge 0.14.0 closes out a run of releases focused on speed and on diagnosing problems instead of guessing at them: batched image transfers, faster USB discovery, a full diagnostics report, and per-model device tuning.

{/* truncate */}

## Performance

- Batched image transfers on 293S-family devices.
- One HID enumeration per probe sweep instead of one per model.
- Adaptive reconnect: 3 s polling while enumeration is fast, backing off to 30 s when it is not.
- Fewer hot-path allocations, less FFI churn, and quieter WebSocket traffic.

Batching is the one you can see: a profile switch now paints the whole panel in one sweep instead of key by key.

## Diagnostics you can attach to a bug report

`deckbridge diagnose` prints a complete report without starting a server or opening the device, and the Web UI serves the same report from `GET /api/diagnostics`. It includes the resolved device model, capability probes, log excerpts, and your `settings.json`. Commands are included verbatim by default — pass `--redact-commands` if you would rather not share them.

Deckbridge also writes a rotating log file now (2 MB, 3 files kept). Startup steps are wrapped in paired breadcrumbs, so a freeze leaves the hung step as the last line in the log.

## Device tuning overrides

If a device is almost right but not quite, `modelOverrides` in `settings.json` (and the tuning panel in the Web UI) lets you adjust image, wire, and key-map settings for a model without a code change. Identity fields — VID/PID, protocol, driver kind, geometry — stay fixed on purpose: no override can make Deckbridge pick a different driver. Start with `DECKBRIDGE_NO_OVERRIDES=1` if a tweak makes things worse.

See [troubleshooting](/troubleshooting) for both features.

## Device and platform fixes

- macOS: HID enumeration recovers after an unplug/replug instead of wedging.
- AKP153E: stable discovery and corrected icon dimensions.
- Stream Deck MK.2: fixed splash rotation and the gen2 key offset.
- Device tuning reloads are now race-proof.

## Releases

Every release artifact is scanned for malware, and the VirusTotal links are in the release body. Windows and macOS installer builds are faster, with a retry for the flaky macOS DMG step.

## In the future release

Deckbridge will dock a single deck by default and stop scanning USB once one is connected. Set `"multiDeck": true` (or use the Settings toggle) to dock a second deck; turning it back off tears the extra dock down.
