DeckBridge 0.18.0 (October 1) and 0.19.0 (October 5) are out. A phone can now act as a deck. Other tools can push text onto side keys. Idle decks can dim, and the Web UI got a full redesign.

{/* truncate */}

All screenshots below come from the real Web UI in mock mode. A test client stands in for the Elgato app, and the key art is placeholder. "Before" shots come from 0.17.0, "after" shots from 0.19.0.

## Use a phone or tablet as a deck

New in 0.18. A phone or tablet browser becomes one more 15-key deck. The Elgato app sees it as a normal Network Dock. Tap a key to run its action. Hold a key for long-press actions.

<ThemedImage

The feature is off by default. Turn it on in **Settings → Browser deck**, then press **Pair a device**. Open the shown address on the phone and enter the 6-digit code. A QR code is optional; it needs a small download from jsDelivr.

The Elgato app pairs one dock per IP address. **Need another address?** walks you through adding one. The connection uses plain HTTP, so use a trusted network. See [Browser deck](/browser-deck).

## Push text onto side keys

New in 0.18. Scripts and other tools can now write text onto side keys and touch-strip zones. Pick **Push API (external)** as the widget and enter a channel name. Create a token in **Settings → Push API**. Then send one HTTP request:

```bash
curl -X POST http://127.0.0.1:3000/api/push/obs-rec \
  -H "Authorization: Bearer $DECKBRIDGE_PUSH_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text": "REC\n01:23:45", "background": "#c0392b"}'
```

Values expire after a time-to-live, ten minutes by default. The `deckbridge push` command does the same from a shell. The repository has [examples](https://github.com/lukasMega/DeckBridge/tree/main/examples/push) for Home Assistant and an OBS recording timer. See [Push API](/push-api).

## Standby and burn-in care

New in 0.19. Cheap LCD panels can keep a ghost of a static image. A bright deck also glares at night. **Settings → Standby & burn-in care** now handles both, per deck:

- **Dim when idle** lowers brightness after a set time without input.
- **Screen off** follows as a second idle stage.
- **Wake press** decides if the first press only wakes the deck.
- **When the Elgato app is away**, the deck keeps its images, shows a dim clock, or goes dark.
- **Night mode** caps brightness between two times.
- **Pixel shift** moves DeckBridge's own widgets by 1 px every five minutes.

## Slim font for widget text

New in 0.19. Side keys and strip zones get a third font, **Slim**. It is an anti-aliased Barlow Condensed, so longer text stays readable. **Tight lines** packs rows closer, and line gap now goes down to −8 px.

<ThemedImage

Older builds drop side-key settings that use Slim or a negative line gap. Keep this in mind before you downgrade. See [Text style](/side-keys#text-style).

## Docs open inside the app

Every docs link in the Web UI now has a second button. It opens the page in a dialog above the app, so you keep your place. **Open in new tab** still works.

<ThemedImage
  sources={{

  }}
  alt="Documentation dialog over the Web UI showing the Push API docs page"
  width={454}

Docs links now go through a local `/go/docs/<topic>` redirect. The daily ping includes the topic names opened since the last ping. Nothing is recorded while the ping is off. See [Privacy](/privacy#the-deckbridge-app).

## Fixes

- BMP output now pads rows correctly. Image widths not divisible by 4 no longer produce broken files.
- Touch-strip partial updates are tracked by exact rectangle, so two updates can't mix.
- Sockets, commands, caches, logs and previews now have firm limits. Shutdown saves settings and closes everything together.
- The side-keys help shows the right Stream Deck + grid for the AKP05.

## Release status

0.19.0 includes everything above. Browser deck and Push API arrived in 0.18.0. [Download 0.19.0](https://github.com/lukasMega/DeckBridge/releases/tag/deckbridge-v0.19.0).

Isolated test builds of 0.19.0 were scanned on VirusTotal before release. See [VirusTotal results](/virustotal). Verify downloads with the release checksums.
