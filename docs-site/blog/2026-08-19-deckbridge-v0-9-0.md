Deckbridge 0.9.0 shrinks its embedded txiki.js runtime from 6.4 MB to 2.4 MB. Linux releases also gain broader compatibility.

<!-- truncate -->

## Highlights

- Reduces embedded runtime size by more than half.
- Builds Linux x86_64 releases on Ubuntu 24.04.
- Fixes compatibility with older glibc environments.
- Refreshes CI actions and docs dependencies.
